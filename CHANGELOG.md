# История изменений DekstopShot

## 1.3.0 — 12 ноября 2026

- Добавлена фоновая работа без значка в трее. Повторный запуск открывает окно работающего экземпляра.
- Карта мониторов показывает компактную сетку, когда экраны не помещаются на схеме.
- Обновлены меню трея, статус снимка, заливка галочек и скругление окна. Исправлена большая дуга поверх интерфейса.

[Full Changelog: v1.2.0...v1.3.0](https://github.com/fobesyka-beep/DekstopShot/compare/v1.2.0...v1.3.0)

## 1.2.0 — 5 ноября 2026

### Добавлено

- Настройка **Сохранять в «Изображения» / Save to Pictures**. При включении снимок дополнительно записывается в PNG в подпапке **DekstopShot** системной папки «Изображения».
- Учитывается фактическое расположение системной папки, включая перенаправление. Уникальные имена предотвращают перезапись снимков; PNG сохраняется без потерь.
- При ошибке записи в файл скопированное изображение остаётся в буфере, а приложение сообщает о проблеме.

### Изменено

- «Инструкция» расположена под полной подписью «СНИМОК В БУФЕР ОБМЕНА», заголовок «Общее» выровнен по центру. Убраны подпись «Язык», стрелки на кнопках AI-сервисов и пункт «Сделать снимок» из меню трея.
- Обновлены встроенная инструкция, README и USAGE для настройки сохранения и новой компоновки.
- Сохранение в файлы по умолчанию выключено. Старые настройки продолжают загружаться; включить новую функцию можно вручную.

[Full Changelog: v1.1.0...v1.2.0](https://github.com/fobesyka-beep/DekstopShot/compare/v1.1.0...v1.2.0)

## 1.1.0 — 4 ноября 2026

### Добавлено

- Английский интерфейс и переключатель **Русский / English**. При первом запуске язык выбирается по Windows, последующий выбор пользователя сохраняется.
- Фоновая проверка последнего стабильного GitHub Release при запуске. При наличии новой версии появляется ссылка на её страницу; установка остаётся ручной.
- Настройка **«Не блокировать клавишу» / “Allow the key in other apps”**: горячая клавиша может одновременно запускать захват и поступать в активную программу. Режим включён по умолчанию.

### Изменено

- Боковая навигация содержит только инструкцию. Язык, пауза и скрытие в трей объединены в блок «Общее» / “General”.
- Статус захвата перенесён в блок горячей клавиши; удалены повторяющиеся подсказки и кнопка «Скриншот».
- Встроенная инструкция, меню трея, диалог сочетания и документация актуализированы для двух языков и новых настроек.
- Настройки 1.0 продолжают загружаться; поля `language` и `hotkey_passthrough` добавляются без сброса выбранного монитора и сочетания.
- Описание GitHub Release берётся из отдельного файла с изменениями версии.

### Поведение обновлений

- Офлайн, отсутствие релиза и ограничения GitHub не мешают запуску приложения.
- Проверка получает только публичные сведения о релизе, без скриншотов, авторизации и API-ключей. Автоматической установки нет.

[Full Changelog: v1.0.0...v1.1.0](https://github.com/fobesyka-beep/DekstopShot/compare/v1.0.0...v1.1.0)

## 1.0.0

- Первый Windows-выпуск: захват выбранного монитора или окна в системный буфер, настройка глобальной клавиши, пауза и работа в трее.
- Интерфейс Liquid Glass, выбор источников и быстрые ссылки ChatGPT, Gemini, Claude и Google.
- Сборка Windows x64, упаковка полной папки с `_internal`, автоматическая публикация по тегам `v*`.

Границы фактических проверок каждой подготовленной сборки перечислены в [VALIDATION.md](VALIDATION.md).
