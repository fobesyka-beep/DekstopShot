# Подробная инструкция DekstopShot для Windows

Скриншот выбранного монитора **или окна приложения** в системный буфер обмена по одной горячей клавише.
Интерфейс на русском, в стиле Liquid Glass: прозрачный размытый фон, стеклянные кнопки-капсулы с голубым контуром, круглые элементы и мягкие блики при наведении.

Сборку `.exe` создаёт `Build_EXE.cmd` на Windows; результат находится в `dist\DekstopShot`.

## Что умеет

- Глобальная клавиша **−** по умолчанию — минус над буквами. Num − считается отдельной клавишей.
- Смена клавиши записью нажатия, включая сочетания с Ctrl, Alt и Shift.
- Проверка, не занято ли сочетание Windows или другой программой.
- Закрепление конкретного монитора. Выбор сохраняется по идентификатору устройства, а не номеру в списке.
- Мониторы слева, справа или выше основного, отрицательные координаты и разные масштабы DPI.
- Режим **«Окно приложения»**: выбор конкретного открытого окна; одинаковые заголовки различаются по дескриптору окна и процессу.
- Захват окна через Windows Graphics Capture. Перекрывающие окна не добавляются к снимку выбранного приложения.
- Изображение в буфере в форматах DIB и PNG — для вставки в редакторы, чаты и браузер.
- Значок и меню в трее; крестик скрывает настройки. Окно настроек не создаёт кнопку на панели задач.
- Пауза, освобождающая горячую клавишу, и настройка запуска сразу в трей.
- Успешный снимок не показывает системное уведомление; короткий статус остаётся внутри настроек.
- Кнопки ChatGPT, Gemini, Claude и Google с цветными иконками, открывающие сайты в браузере по умолчанию. Те же ссылки и иконки доступны в меню трея.
- Один экземпляр приложения на пользовательский сеанс.

Скриншоты приложение не записывает в файлы и не отправляет в сеть. В настройках хранятся выбранный монитор, режим, горячая клавиша и запуск в трей. Старое поле `notifications` принимается для совместимости, но не включает уведомления. Историю буфера обмена и его синхронизацию отдельно контролирует Windows.

## Быстрый запуск

Нужны **Windows 10 22H2 / Windows 11 x64** и **Python 3.12 x64**. Также подходят Python 3.10–3.13.
Python: <https://www.python.org/downloads/windows/>. При установке включите **Add Python to PATH** и Python Launcher.

1. Распакуйте архив целиком в обычную папку, например `C:\Apps\DekstopShot`.
2. Дважды нажмите **`Start_DekstopShot.cmd`**.
3. Первый запуск создаст `.venv` и установит зависимости; для этого нужен интернет. Загрузка PySide6 может занять несколько минут.
4. В окне DekstopShot выберите источник: монитор или приложение. В режиме приложения выберите нужное открытое окно.
5. Нажмите **−**, затем вставьте снимок через **Ctrl + V** в нужную программу.

После подготовки Python запускается через `pythonw.exe`, без консольного окна. Небольшое окно подготовки при запуске `.cmd` закрывается после старта программы.

При повторном запуске зависимости проверяются локально; интернет потребуется, если что-то не установлено.

**Одиночная клавиша резервируется для снимка.** Чтобы вводить минус как обычно, назначьте, например, Ctrl + Alt + S, либо включите паузу в меню трея.

### Работа в фоне

Крестик и «Скрыть в трей» прячут настройки. DekstopShot продолжает слушать клавишу.
Значок ищите рядом с часами, в том числе под стрелкой скрытых значков. Щелчок открывает настройки, правая кнопка — меню.
Для завершения выберите **«Выйти из DekstopShot»**. Переключатель «При запуске — сразу в трей» не добавляет программу в автозагрузку Windows.

### Выбор приложения

Выберите «Окно приложения», затем строку `имя.exe — заголовок окна`.
Список обновляется при открытии настроек, по кнопке обновления и периодически, пока настройки видны.

- Захватывается выбранное окно, включая его рамку, если она предоставляется Windows.
- Окно должно быть открыто и не свёрнуто. Оно может находиться позади других окон или на другом мониторе.
- После закрытия окна или перезапуска DekstopShot выберите окно заново. HWND не сохраняется на диск и не используется в новом сеансе.
- Если приложение содержит несколько окон, выбирается одно конкретное окно; все окна процесса не объединяются в один снимок.
- При перезапуске в режиме приложения настройки откроются для выбора окна, даже если включён запуск в трей.
- Одноразовый захват окна запускается в отдельном процессе с ограничением ожидания 8 секунд. Поэтому он может занимать больше времени, чем снимок монитора.
- На Windows с build ≥20348 (включая Windows 11) до первого кадра запрашивается `draw_border=False`. На Windows 10 22H2 build 19045 API отключения жёлтого индикатора отсутствует, и сохраняется системная рамка. Другие активные сеансы захвата и системные разрешения также могут влиять на индикатор; см. [IsBorderRequired](https://learn.microsoft.com/en-us/uwp/api/windows.graphics.capture.graphicscapturesession.isborderrequired).
- Защищённое содержимое, DRM-видео, закрытые или недоступные системные окна могут не захватываться.

При отключении закреплённого монитора приложение не начинает снимать другой экран: выберите доступный монитор. При возвращении того же устройства сохранённый выбор снова используется, если Windows сохранила его идентификатор. Смена порта/видеокарты может потребовать повторного выбора.

### ChatGPT, Gemini, Claude и Google

Кнопки открывают сайты. В ChatGPT, Gemini или Claude вставьте скриншот вручную через Ctrl + V; может потребоваться вход в аккаунт. На узком окне четыре кнопки располагаются в два ряда.
Google открывает обычный веб-поиск, без автоматической загрузки картинки или поиска через Lens.

## Получить `.exe`

На Windows дважды запустите **`Build_EXE.cmd`**. Скрипт установит инструменты сборки, выполнит тесты и создаст:

```text
dist\DekstopShot\DekstopShot.exe
```

После сборки Python пользователю приложения не нужен. Для переноса копируйте **всю папку `dist\DekstopShot`**, включая `_internal`, а не только `.exe`.
Папочная сборка сохраняет библиотеки Qt отдельно и позволяет их заменять. Установщик и цифровая подпись в этой версии не включены.

Альтернатива: загрузите проект в свой GitHub-репозиторий и запустите workflow **Windows build** через Actions → Run workflow.
После успешного выполнения скачайте артефакт `DekstopShot-Windows-x64`. Подготовка веток, выпуск релизов и публикация пакета описаны в [руководстве по публикации](PUBLISHING.md).

### Ручной запуск и сборка

В терминале из папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\pythonw.exe main.py
```

Для сборки:

Сборка для Windows выполняется на Windows: <https://pyinstaller.org/en/stable/>.

## Дизайн и техническая реализация

Компактное окно настроек — 940 × 590 логических пикселей, минимальный размер 800 × 520. Удалены большой промоблок с кнопкой снимка, верхний заголовок и индикатор готовности; захват вызывается горячей клавишей или из трея. На узком окне ссылки переходят в два ряда, содержимое остаётся доступным через прокрутку.

Материал обновлён по мотивам [статьи kube.io](https://kube.io/blog/liquid-glass-css-svg/): прозрачная середина, объёмная кромка линзы, противоположные отражения и блик, следующий за курсором. Это отрисовка Qt поверх нативного размытия, без SVG-преломления пикселей рабочего стола. [pyqt-liquidglass](https://github.com/kotikotprojects/pyqt-liquidglass) использует API macOS и на Windows ничего не делает, поэтому зависимость не добавлялась. Нативная область окон и диалогов обрезается по скруглённой форме, чтобы DWM не оставлял прямоугольные углы.

На Windows 11 22H2+ программа запрашивает нативный Desktop Acrylic через DWM. На Windows 10 используется дополнительная проверка доступности Acrylic через `SetWindowCompositionAttribute`; этот необязательный системный API не требуется для запуска приложения.
Размытие применяется после появления окна и повторно при его открытии из трея. Поверх него рисуется лёгкая полупрозрачная тонировка: фон рабочего стола остаётся виден сквозь окно. Диалог горячей клавиши и инструкция используют тот же материал.
Кнопки рисуются как прозрачные капсулы с голубой кромкой, внутренним отражением и движущимся бликом. Одиночная горячая клавиша отображается в круглой стеклянной линзе.
Когда фон недоступен, используется более плотный градиент для читаемости. Вид и доступность размытия зависят от Windows и её параметров прозрачности.
Это интерфейс, вдохновлённый Liquid Glass; системные материалы Apple не используются.

Монитор захватывается через `EnumDisplayMonitors`, `GetMonitorInfoW`, `CreateDIBSection` и `BitBlt` в физических пикселях. Режим Per-Monitor DPI V2 задаётся до создания окон и в манифесте сборки.
Горячая клавиша регистрируется через `RegisterHotKey` с `MOD_NOREPEAT`, а не через глобальный перехват клавиатуры.
Окно приложения захватывается через пакет `windows-capture` по HWND; при неудаче программа не подменяет его снимком всего экрана.
Тяжёлая работа выполняется вне потока интерфейса. Если буфер временно занят, запись повторяется с короткими интервалами.
Права администратора не требуются.

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа для запуска и сборки |
| `dekstopshot/core.py` | Настройки, цели захвата, горячие клавиши, формат DIB |
| `dekstopshot/native.py` | Типизированные вызовы Windows API, монитор, буфер обмена |
| `dekstopshot/capture.py` | Фоновый захват, PNG, отдельный процесс захвата окна |
| `dekstopshot/hotkeys.py` | Регистрация клавиши и обработка сообщений Windows |
| `dekstopshot/ui.py` | Стеклянный интерфейс, карта мониторов, выбор окна |
| `dekstopshot/services.py` | Ссылки ChatGPT, Gemini, Claude и Google для окна и трея |
| `dekstopshot/app.py` | Трей, жизненный цикл и связь интерфейса с захватом |
| `tools/preview.py` | Предпросмотр реальных виджетов с демонстрационными данными |

## Настройки и диагностика

Настройки: `%LOCALAPPDATA%\DekstopShot\settings.json`.
Журнал ошибок: `%LOCALAPPDATA%\DekstopShot\dekstopshot.log`.
При первом запуске под новым именем DekstopShot импортирует корректные настройки из `%LOCALAPPDATA%\GlassShot\settings.json`, если новых настроек ещё нет. Исходный файл прежней версии остаётся без изменений. Существующие настройки DekstopShot имеют приоритет.
При повреждении JSON исходный файл по возможности сохраняется как `settings.broken-ДАТА.json`, а приложение загружает начальные настройки.

| Ситуация | Решение |
| --- | --- |
| Клавиша занята | Откройте настройки и назначьте другую комбинацию; затем снимите паузу |
| После закрытия окна ничего не видно | Откройте значок DekstopShot в трее рядом с часами |
| Выбранное окно свёрнуто | Разверните его, затем повторите снимок |
| Монитор не найден | Нажмите обновление и выберите подключённый экран |
| Буфер занят | Закройте диалог/программу, удерживающую буфер, и повторите снимок |
| Окно даёт пустой/защищённый кадр | Проверьте ограничения самого приложения; защищённый контент не обходится |
| Запуск из исходников не удался | Выполните `.\.venv\Scripts\python.exe main.py` в терминале и посмотрите текст ошибки |
| Зависимости не установились | Проверьте Python x64 3.10–3.13 и доступ к PyPI; повторите запуск |

## Проверка версии

Встроенный диагностический прогон: `python main.py --self-test` или `dist\DekstopShot\DekstopShot.exe --self-test` из корня проекта. Закройте работающий DekstopShot перед проверкой mutex. Проверяются реальный GDI, WGC через дочерний процесс, конфликт и освобождение сочетания, mutex и отклонение свёрнутого/закрытого тестового окна. Флаг `--clipboard` дополнительно заменяет содержимое системного буфера синтетическим изображением 2 × 2 и проверяет чтение DIB/PNG. Снимки рабочего стола и окон остаются в памяти; JSON-отчёт сохраняется в `.validation\windows-smoke.json` (для exe — относительно текущей рабочей папки), путь можно изменить через `--output`. Прогон из exe проверяет WGC внутри сборки, но не подтверждает физическое нажатие клавиши, вставку в стороннюю программу, работу основного Controller через интерфейс и внешний вид Acrylic.

См. [VALIDATION.md](../VALIDATION.md): перечислены выполненные автоматические проверки и ручная проверка на Windows.
Предпросмотры [монитора](preview-monitor.png) и [окна приложения](preview-application.png) показывают реальные виджеты Qt с демонстрационными мониторами, приложением и фоном. В предпросмотре размытие демонстрационного фона выполняет Qt; это не скриншот рабочего стола Windows и не проверка системного Acrylic. Для отдельного предпросмотра непрозрачного запасного оформления используйте `python tools/preview.py --flat`.
