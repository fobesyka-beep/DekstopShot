## Что изменилось

- Добавлен **английский язык** и переключение **Русский / English**. При первом запуске выбирается язык Windows, затем сохраняется выбор пользователя.
- Добавлена **проверка обновлений при запуске**. Если доступен более новый стабильный релиз, приложение показывает ссылку на страницу скачивания. Офлайн и ошибки GitHub не мешают работе; автоматической установки нет.
- Добавлена настройка **«Не блокировать клавишу» / “Allow the key in other apps”**. По умолчанию нажатие запускает снимок и продолжает работать в активном приложении; для эксклюзивного захвата настройку можно отключить.
- Удалена кнопка **«Скриншот»** из боковой навигации: оставлена инструкция. Язык, пауза и скрытие в трей объединены в блок **«Общее» / “General”**.
- Статус снимка перенесён в блок горячей клавиши, убраны повторяющиеся подписи и подсказки.
- Обновлены встроенная инструкция, меню трея, диалог горячей клавиши и документация. Настройки версии 1.0 продолжают загружаться без сброса источника и сочетания.

Скачивайте **DekstopShot-Windows-x64.zip**, полностью распаковывайте папку `DekstopShot` и запускайте `DekstopShot.exe`. Папка `_internal` должна оставаться рядом с exe; отдельный Python не нужен.
