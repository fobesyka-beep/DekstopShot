## Что изменилось

- Добавлена настройка **Сохранять в «Изображения» / Save to Pictures**: снимок можно одновременно копировать в буфер и сохранять в PNG в подпапке **DekstopShot** системной папки **«Изображения»**.
- Сохранение **выключено по умолчанию**. Выбор запоминается; при отключении ранее созданные файлы остаются на месте.
- Используется фактическая папка «Изображения», включая перенаправление в Windows/OneDrive. Уникальные имена не дают перезаписывать старые снимки. Ошибка записи не удаляет снимок из буфера.
- «Инструкция» расположена под подписью **«СНИМОК В БУФЕР ОБМЕНА»**, заголовок **«Общее»** выровнен по центру. Убраны подпись «Язык», стрелки на кнопках сервисов и пункт **«Сделать снимок»** из меню трея. Захват выполняется горячей клавишей.
- Обновлены инструкция и документация. Сохранены RU/EN, проверка обновлений, оба режима горячей клавиши и совместимость с настройками 1.0/1.1.

Скачивайте **DekstopShot-Windows-x64.zip**, полностью распаковывайте папку `DekstopShot` и запускайте `DekstopShot.exe`. Папка `_internal` должна оставаться рядом с exe; отдельный Python не нужен.
