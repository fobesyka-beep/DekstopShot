## Что изменилось

- Добавлена опция **«Работать без значка в трее»**. Повторный запуск DekstopShot открывает окно уже работающего приложения. Подсказка объясняет это при наведении.
- Для плотных раскладок мониторов карта показывает сетку с номерами из списка.
- Пункты меню трея разделены, заливка галочек стала мягче, а рамка окна согласована со скруглением Acrylic. Исправлена большая дуга поверх интерфейса.

Скачайте **DekstopShot-Windows-x64.zip**, распакуйте всю папку `DekstopShot` и запустите `DekstopShot.exe`.
